# KerBudget

Application PWA de gestion du budget 2026.

## Mise en ligne sur GitHub Pages

1. Créer un dépôt GitHub nommé `KerBudget`.
2. Envoyer tous les fichiers de ce dossier directement à la racine du dépôt.
3. Dans **Settings → Pages** :
   - Source : **Deploy from a branch**
   - Branch : **main**
   - Folder : **/ (root)**
4. Enregistrer.
5. Ouvrir l’adresse GitHub Pages dans Chrome sur Android.
6. Utiliser **Installer l’application** ou **Ajouter à l’écran d’accueil**.

Le nom affiché sur le téléphone sera **KerBudget**.
